PUT YOUR PHOTOS IN THIS FOLDER
==============================

Use exactly these file names (all lowercase, ending in .jpg):

  cover.jpg      -> big photo of the two of you at the top (portrait looks best)
  photo1.jpg
  photo2.jpg
  photo3.jpg
  photo4.jpg
  photo5.jpg
  photo6.jpg
  photo7.jpg
  photo8.jpg
  photo9.jpg     -> gallery photos

Tips
- Vercel is case-sensitive: "Photo1.JPG" will NOT load. Rename to "photo1.jpg".
- Keep each photo under about 500 KB so the site loads fast
  (squoosh.app can shrink them for free).
- Using .png or .webp? Change the file names in js/script.js (top of the file).
- Want more or fewer photos? Add or remove lines in the "photos" list in js/script.js.
- Until a photo exists, a pretty placeholder is shown, so the site never looks broken.
